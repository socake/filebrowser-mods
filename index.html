Features

不止是文件管理器

在经典 filebrowser 之上，补齐了对外分享与文档协作的关键一环。

公开文档门户 /docs

无需登录的只读门户：左侧目录树、右侧预览，支持 Markdown、代码高亮与 drawio 图，把目录直接当在线文档库对外发布。

免登录投递箱

任何人 POST 一个文件即可拿到永久分享链接，文件自动归档、加时间戳防冲突。适合收集作业、外部投稿。

增强分享页

分享链接支持 Markdown / 文本在线预览与语法高亮，密码分享流程更顺，不再只能盲下载。

Markdown 优先

内置一套完整 Markdown 渲染样式与可预览编辑器，写文档、记笔记、发布说明，所见即所得。

更稳的安全底线

分享 hash 熵提升到 24 字节，极难被遍历猜测；文档门户自动过滤 .env / 密钥 / 凭据类敏感文件。

自托管 · 单二进制

一个可执行文件加一个数据库即可运行，前端已内嵌。指向一个目录，立刻拥有自己的私有云。

Why self-host

数据归你，不归平台

不依赖第三方网盘、没有容量套餐、没有隐私让渡。装在你自己的服务器或内网，文件从头到尾在你掌控之中。

零订阅

开源、自托管，容量只取决于你自己的磁盘。

内网友好

可纯内网部署，敏感资料不出局域网。

可定制

开源代码，门户、分享、品牌都能按需改造。

Deploy

一行命令，跑起来

Docker 拉起，指向要暴露的目录即可。几秒钟后访问浏览器界面。

查看部署文档 →
# 用 Docker 启动 LumenBrowser
docker run -d \
  -p 8080:80 \
  -v /srv/files:/srv \
  -v ./database.db:/database.db \
  lumenbrowser/lumenbrowser

# 浏览器打开
→ http://localhost:8080
