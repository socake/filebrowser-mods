经典 filebrowser 的核心：把服务器上一个目录变成可在浏览器操作的私有云。

浏览与基础操作

上传、下载、删除、重命名、移动、复制，完整文件树操作。

/api/resources · GET POST PUT PATCH DELETE

大文件断点续传

基于 tus 协议分块上传，断网可续传，适合大文件与弱网。

/api/tus

在线预览

图片缩略图、视频、字幕、文本与代码语法高亮，无需下载即可查看。

/api/preview · /api/raw · /api/subtitle

在线编辑

直接在网页里编辑文本与代码文件并保存。

文件搜索

按文件名/路径检索，快速定位。

/api/search

磁盘用量

查看挂载目录的容量占用统计。

/api/usage

多用户隔离与细粒度访问控制，适合团队共享同一实例。

多用户与登录

注册、登录、JWT 鉴权与 token 续期。

/api/login · /api/signup · /api/renew

用户作用域 scope

为每个用户限定可见的根目录，互相隔离。

/api/users

访问规则 rules

按路径配置 allow/deny 规则，精确控制可访问范围。

命令执行（可选）

可配置允许在指定目录执行的 shell 命令（command runner）。

/api/command

filebrowser users / config / rules …

把文件或目录生成对外链接，可控、可追溯。

分享链接

为任意文件/目录生成分享链接并管理。

/api/share · /api/shares

密码与过期

分享可设访问密码、可设过期时间。

分享 hash 安全加固 新增

分享 hash 熵从 6 字节提升到 24 字节，极难被遍历猜测。

http/share.go

增强分享页 新增

分享链接支持 Markdown / 文本在线预览与语法高亮，不再只能盲下载。

Share.vue · http/public.go

本分支的核心差异化：在私有文件管理之上，叠加了一层对外的文档与投递能力。

公开文档门户 /docs 新增

免登录只读门户：目录树 + 内容预览，支持 Markdown、代码高亮、drawio 图，把目录当在线文档库对外发布。

/docs · /docs/list · /docs/content

免登录投递箱 新增

任何人 POST 一个文件即得永久分享链接，自动归档加时间戳，适合收集投稿/作业。

POST /api/public/upload

Markdown 优先 新增

内置完整 Markdown 渲染样式与可预览编辑器，写文档所见即所得。

mdPreview.css · Editor.vue

敏感文件过滤 新增

门户列表/预览自动跳过 .env、密钥、凭据类敏感文件。

规划中的命令行客户端，把现有 REST API 封装成终端命令——服务端无需改动。支持脚本化、CI 集成、批量上传与定时备份。

命令作用背后 API
lumen login <url>登录并保存连接配置（profile）POST /api/login
lumen ls <远程路径>列出远程目录GET /api/resources
lumen put <本地> <远程>上传文件（大文件断点续传）/api/tus
lumen get <远程> <本地>下载文件GET /api/raw
lumen rm / mv / mkdir删除 / 移动重命名 / 新建目录DELETE PATCH POST /api/resources
lumen share <远程>生成分享链接（--password / --expires）POST /api/share
lumen shares列出我的所有分享GET /api/shares
lumen search <关键词>搜索文件GET /api/search
lumen drop <文件>免登录投递，上传即得永久链POST /api/public/upload
技术路线：单独的 Go 二进制（与产品「单二进制」调性一致，跨平台分发），纯调 REST，复用仓库内 share/files 包的结构体。最小验证建议先做 login + ls + drop 跑通链路。

面向自托管，分发与运维都尽量简单。
